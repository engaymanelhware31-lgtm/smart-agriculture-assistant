# مساعد الزراعة الذكي | Smart Agriculture Assistant
نسخة ويب تأسيسية متكاملة للواجهة، باللغة العربية وبدعم RTL، مناسبة للنشر على GitHub Pages.

## الملفات
- `index.html`: الصفحة الرئيسية والنوافذ.
- `styles.css`: التصميم المتجاوب.
- `app.js`: البحث والتصفية وعرض ملفات المحاصيل والإضافة المحلية والتصدير.
- `data/crops.json`: تصنيفات و36 محصولاً كبداية.

## التشغيل
افتح الموقع المنشور عبر GitHub Pages، أو شغّل المشروع محلياً باستخدام خادم محلي مثل VS Code Live Server. بسبب استخدام `fetch` لقراءة `data/crops.json`، لا تفتح `index.html` مباشرة عبر `file://`.

## الرفع إلى GitHub
ارفع جميع محتويات المجلد إلى جذر المستودع `smart-agriculture-assistant` مع الحفاظ على مجلد `data`:
```bash
git add .
git commit -m "Publish complete agriculture assistant MVP"
git push origin main
```
ثم انتظر اكتمال نشر GitHub Pages.

## تنبيه مهم حول الوظائف
- النسخة الحالية واجهة ويب ثابتة (Static MVP)، ولا تحتوي على Backend أو قاعدة بيانات مركزية أو تسجيل دخول.
- إضافة محصول من لوحة إدارة المحتوى تحفظه في `localStorage` على نفس المتصفح والجهاز فقط. لا تظهر الإضافة تلقائياً للزوار الآخرين.
- زر تصدير JSON يتيح تصدير بيانات المحاصيل المحمّلة، لكنه لا يرفعها تلقائياً إلى GitHub.
- بيانات المحاصيل الحالية تشمل أسماء وتصنيفات وأسماء علمية أولية. أقسام الأصناف ومواعيد الزراعة والمسافات والري والتسميد والمكافحة والحصاد هي حقول جاهزة لاستكمالها بمراجع رسمية موثوقة حسب الدولة والمحافظة والموسم والتربة ومصدر المياه. لا تستخدمها كجرعات أو توصيات ميدانية.
- رفع صور النباتات وتحليلها غير موجودين في هذه النسخة وفق نطاق المشروع المعتمد.
- لا توجد بعد نسخة Android؛ يمكن تطويرها لاحقاً بعد تثبيت API وقاعدة البيانات المشتركة.

## النشر
GitHub repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
