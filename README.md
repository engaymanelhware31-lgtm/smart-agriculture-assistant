# مساعد الزراعة الذكي | Smart Agriculture Assistant

نسخة تأسيسية لواجهة ويب عربية (RTL) لمشروع موسوعة المحاصيل وإدارة المزرعة.

## محتويات المشروع
- `index.html`: هيكل الصفحة.
- `styles.css`: التصميم والتجاوب مع الهاتف والحاسوب.
- `app.js`: بيانات تجريبية للمحاصيل والبحث والتصفية وعرض التفاصيل.

## تشغيل المشروع محلياً
1. حمّل الملفات أو استنسخ المستودع.
2. افتح المجلد في VS Code.
3. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.

لا يحتاج هذا النموذج إلى تثبيت حزم أو إعداد خادم.

## رفع الملفات إلى GitHub
ضع الملفات الثلاثة وملف README داخل جذر المستودع، ثم نفّذ:

```bash
git add .
git commit -m "Initial agricultural assistant web prototype"
git push origin main
```

## تفعيل GitHub Pages
من المستودع: Settings → Pages → Deploy from a branch → اختر `main` والمجلد `/ (root)` ثم Save.

## ملاحظات مهمة
- البيانات الموجودة في `app.js` تجريبية لعرض الواجهة فقط، وليست توصيات زراعية للاستخدام الميداني.
- لا توجد حالياً قاعدة بيانات أو تسجيل دخول أو API أو تطبيق Android.
- رفع الصور وتحليلها مستبعدان من النسخة الأولى حسب نطاق المشروع المعتمد.
- ستُضاف التوصيات الزراعية بعد توثيق مصادرها وربطها بالمحافظة والموسم ونوع التربة ومصدر المياه.
- يفضل نقل بيانات المحاصيل لاحقاً إلى قاعدة بيانات وخادم API بدلاً من بقائها داخل `app.js`.
