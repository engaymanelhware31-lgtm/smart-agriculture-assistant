مساعد الزراعة الذكي – تحديث قسم الحبوب

محتويات الحزمة:
- index.html: ملف الموقع الكامل، يتضمن المحاصيل الستة التفصيلية مع المحافظة على بقية المحاصيل والبيانات الموجودة.
- grain-crops-eg.json: بيانات مستقلة للمحاصيل الستة للاحتفاظ بها وتطوير قاعدة البيانات لاحقاً.

المحاصيل: القمح (الخبز والصلب)، الأرز، الذرة الشامية الصفراء، الذرة الشامية البيضاء، الشعير، الذرة الرفيعة.

طريقة الرفع مرة واحدة:
1. افتح مستودع GitHub الخاص بالتطبيق.
2. ارفع index.html من هذه الحزمة إلى جذر المستودع مع استبدال الملف القديم.
3. اضغط Commit changes.
4. انتظر تحديث GitHub Pages ثم افتح الموقع واضغط Ctrl+F5.

ملاحظات علمية:
- المحتوى مخصص لمصر كبداية، ويُكيّف حسب المحافظة والتربة والمياه والصنف والموسم.
- لا توجد جرعات مبيدات أو وصفات كيميائية ثابتة؛ المكافحة مرتبطة بالتشخيص والتسجيل الرسمي وفترة الأمان.
- جداول الاحتياجات المائية لعام 2020 مراجع تاريخية وليست برنامج ري حالي.
- قائمة الأصناف والهجن تُراجع مع نشرة الموسم الحالي ومصدر التقاوي المعتمد.
- الذرة الشامية الصفراء والبيضاء نفس النوع النباتي مع اختلاف لون الحبوب والسوق، والذرة الرفيعة محصول مختلف.
- تفاصيل الهجن البيضاء تحتاج مطابقة نشرة الموسم الرسمية؛ وقد تم توضيح ذلك بدل افتراض أصناف غير مؤكدة.
